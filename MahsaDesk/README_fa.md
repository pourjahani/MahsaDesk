# مهسا دسک

نسخه دسکتاپ ویندوز از کلاینت [مهسانگ](https://github.com/GFW-knocker/MahsaNG) (فورک v2rayNG). برنامه‌ای غیرانتفاعی و مبتنی بر جامعه کاربران، جایی که همه کانفیگ‌های خود را به اشتراک می‌گذارند تا دیگران به اینترنت آزاد دسترسی پیدا کنند.

![مهسا دسک](../Mahsa_logo.jpg)

## 📋 مرور

مهسا دسک یک برنامه دسکتاپ ویندوز برای مدیریت کانفیگ‌های پروکسی V2Ray/Xray است. این برنامه امکانات زیر را فراهم می‌کند:

- اتصال به سرورهای پروکسی با هسته Xray
- مدیریت نشانی‌های اشتراک برای دریافت خودکار کانفیگ سرورها
- تنظیمات پیشرفته مسیریابی، DNS و رمزنگاری
- استفاده از تونل سایفون در کنار کانفیگ‌های پروکسی
- ابزارهای عیب‌یابی شبکه و آزمون سرعت
- سفارشی‌سازی حالت پروکسی سیستم و VPN TUN

این برنامه هم به صورت نصب‌کننده NSIS و هم به صورت نسخه قابل حمل (portable) ارائه می‌شود.

## ✨ امکانات

### امکانات اصلی

- **هسته Xray** (باینری رسمی XTLS) با مدیریت برنامه - SOCKS 10808 / HTTP 10809
- **حالت پروکسی سیستم** - تنظیم خودکار پروکسی ویندوز هنگام اتصال و قطع
- **حالت TUN (آزمایشی)** - وی‌پی‌ان کامل سیستم با sing-box + wintun؛ نیازمند تأیید مدیر (UAC)
- **پشتیبانی از سایفون** - اجرای psiphon-tunnel-core.exe به‌صورت تونل مستقل یا زنجیره روی کانفیگ فعال
- **وارد کردن لینک اشتراک**: vmess/vless (REALITY, XTLS-vision)، trojan، shadowsocks، socks، http، hysteria2 و payloadهای base64
- **ابزارهای QR**: خواندن QR از تصویر کلیپ‌بورد، گرفتن ناحیه‌ای از صفحه و وارد کردن کانفیگ، نمایش هر سرور به‌صورت QR
- **ابزارهای تست**: پینگ TCP، آزمون تأخیر واقعی با هسته موقت (تکی و گروهی)، اعتبارسنجی کانفیگ
- **مسیر هر برنامه (TUN)** - انتخاب برنامه‌هایی که از تونل عبور می‌کنند یا مستقیم می‌روند
- **اشتراک‌ها** - افزودن نشانی با به‌روزرسانی دستی و زمان‌بندی‌شده
- **تکه‌تکه‌سازی TLS** (بسته‌ها/طول/فاصله) متصل به شماره‌گیر TLS در Xray
- **بازنویسی نشانی CDN** - جایگزینی آدرس اتصال با IP کلادفلر با حفظ SNI/Host
- **حالت‌های مسیریابی** - همه از پروکسی / دور زدن ایران (+چین) با مسدودسازی تبلیغات، به‌همراه قوانین سفارشی دامنه
- **مدیریت داده‌های جیو** - مشاهده، به‌روزرسانی و حذف geoip.dat/geosite.dat
- **تنظیمات DNS** (DoH/UDP دور)، شنود ترافیک، MUX، پذیرش TLS ناایمن، اولویت IPv6
- **سینی سیستم** - اتصال/قطع، باز کردن، خروج؛ کمینه‌شدن در سینی، اجرا هنگام ورود به سیستم، اتصال خودکار
- **گزارش‌های زنده هسته** و شمارنده ترافیک نشست
- **پشتیبانی از Hysteria2** - پشتیبانی از لینک‌های hysteria2:// و hy2://؛ اجرا روی موتور TUN
- **ورود از پیوند عمیق** - طرح نشانی `mahsadesk://` برای سپردن کانفیگ به برنامه
- **رابط فارسی (راست‌به‌چپ) و انگلیسی** با تعویض خودکار جهت
- **صادر/وارد کردن کل تنظیمات** (سرورها + اشتراک‌ها + تنظیمات) به‌صورت JSON

### نسخه 0.3.4

- **برگه اتصال** - اتصال یک‌کلیکی با پروکسی سیستم / TUN / تنها سایفون / سایفون بعد از کانفیگ و نمایش زنده وضعیت اتصال
- **جستجوی تنظیمات** - هر تنظیمی را با تایپ پیدا کنید

- **حالت جانشینی** - کلید چرخش خودکار سرورها در تنظیمات
- رفع اشکال‌های گوناگون: گفتگوی اشتراک‌ها، جعبه‌های برگه اتصال، خطای پس از وارد کردن کانفیگ

### آنچه عمداً حذف شده است

سرویس کانفیگ‌های اهدایی مهساNG به بخش‌های بسته‌منبع (رمزنگاری کانفیگ و احراز هویت mahsaserver) وابسته است که در این نسخه دسکتاپ در دسترس نیست. از کانفیگ‌های شخصی یا هر اشتراک عمومی استفاده کنید.

## 🛠️ ساخت از منبع

پیش‌نیازها: Node نسخه ۲۲ یا جدیدتر، Rust (MSVC) و ابزارهای ساخت Visual Studio C++.

```powershell
cd MahsaDesk
npm install
# دانلود xray.exe / sing-box.exe / wintun.dll / فایل‌های جیو در src-tauri/binaries
powershell -NoProfile -ExecutionPolicy Bypass -File .scripts/download-binaries.ps1
npm run tauri build
```

نصب‌کننده NSIS در پوشه `src-tauri/target/release/bundle/nsis/` ساخته می‌شود؛ فایل اجرایی قابل حمل `src-tauri/target/release/MahsaDesk.exe` است (پوشه binaries را کنار آن نگه دارید).

فرآیند CI با برچسب‌های `v*` به‌طور خودکار نسخه‌ها را می‌سازد و منتشر می‌کند.

## 🔒 حریم خصوصی

این برنامه فقط با سرورهای پروکسی شما و نشانی‌های اشتراک شما ارتباط برقرار می‌کند. هیچ آمارگیری و هیچ تله‌متری وجود ندارد. تنظیمات در `%APPDATA%\com.mahsadesk.desktop` ذخیره می‌شود.
